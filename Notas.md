# Texto en negrita y cursiva

**Texto en negrita**
# Esto pone el **texto en negrita**. Se logra rodeando el texto con `**`.
# Se usa para destacar palabras o frases importantes.

*Texto en cursiva*
# Esto pone el *texto en cursiva*. Se hace rodeando el texto con `*`.
# Es útil para resaltar algo o para citas que no necesitan estar en negrita.

**Texto en *negrita y cursiva***
# Puedes combinar **negrita y cursiva**. Se hace colocando primero `**` y luego `*` alrededor del texto.

# Citas

> Esto es una cita.
# El símbolo `>` al principio de la línea convierte todo el texto en una **cita**.
# Es útil para resaltar una idea o frase importante, como si fuera una referencia o un fragmento.
